Combo Ladder: Casual Reward & Feedback SFX

A sound effects pack for match-3, puzzle, idle and other casual games. Its centrepiece is the combo ladder: families of sounds tuned to rise step by step, so each hit in a streak sounds a little bigger than the last. It also covers coins and gems, pops, reward chimes, success and fail stingers, star ratings, countdowns, unlocks, boosters and UI buttons.

  • Format: WAV, 48 kHz, 24-bit
  • Mastering: true peak at or below -1 dBTP, trimmed, with short fades
  • Naming: consistent, e.g. CL_Coin_Pickup_01.wav, sorted by category
  • Status: in production; the sounds on this page are from the current prototype batch
  • Availability: planned for the Unity Asset Store; not yet released

How the sounds are made

Synthesized from original code

Every sound is generated by our own digital signal processing code, using FM and additive synthesis, plucked-string models, filtered noise and a code-generated reverb. No recordings, sample libraries, presets or generative-audio models are used.

Reproducible

Each file is rendered from saved parameters and seeds in a version-controlled project, so every sound can be traced back to the code and settings that made it.

Checked file by file

Automated checks run on every file for peak level, loudness, DC offset, clicks, silence at the start and end, and duration, and every sound is reviewed by ear before release.

Transparency note: the synthesis code was written with the help of an AI coding assistant. The audio itself is not produced by any AI audio model.
